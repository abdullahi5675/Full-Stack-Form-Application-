# Full-Stack Form Application

## 🚀 Project Description
A complete fullstack application with frontend form that communicates with backend API. Built for the weekly task assignment.

## 📋 Task Requirements
- ✅ UI with Name, Email, and Task fields
- ✅ Sends data to backend server
- ✅ Server console.logs received data
- ✅ Server returns same JSON response to UI

## 🛠️ Technologies Used
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Node.js, Express.js
- **Communication**: REST API, Fetch API
